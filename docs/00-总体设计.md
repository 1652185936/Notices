# 华为笔记平替 App — 详细设计文档

> 目标：在 HarmonyOS 4（安卓兼容层）上，做一个功能对标华为笔记的本地笔记应用。
> 技术路线：**安卓 APK（Kotlin + Jetpack Compose）**，侧载安装，长期日常使用。

---

## 一、项目概述

### 1.1 背景
- 设备停留在 HarmonyOS 4，无法升级到 HarmonyOS 5，因此用不了"无界笔记"。
- 鸿蒙 4 保留安卓兼容层，APK 可正常安装并长期使用。
- 目标是做一个**功能对标华为笔记、纯本地优先**的平替，云同步等强生态依赖用替代方案实现。

### 1.2 设计原则
1. **本地优先（Local-first）**：所有数据先落本地数据库，离线完全可用。
2. **隐私优先**：默认数据不出设备；加密笔记单独保护。
3. **渐进交付**：先做能日常使用的 MVP，再逐步补齐高级功能。
4. **可迁移**：数据层与 UI 层解耦，将来换设备/换平台时数据可导出迁移。

### 1.3 功能对标范围（华为笔记完整清单）
| 分类 | 功能 | 优先级 |
|------|------|--------|
| 笔记本体 | 富文本（加粗/斜体/下划线/删除线/字号/颜色/高亮/标题） | P0 |
| 列表 | 无序、有序、待办勾选框 | P0 |
| 插入 | 图片 | P0 |
| 插入 | 手写涂鸦、录音、表格、附件、文档扫描 | P1/P2 |
| 待办模块 | 任务、时间提醒、地点提醒、重复、子任务 | P1 |
| 整理 | 文件夹/分类、标签、搜索、置顶、收藏、排序 | P0/P1 |
| 隐私 | 笔记加密（指纹/密码）、隐私空间 | P1 |
| 数据 | 回收站、本地备份/导入导出 | P0/P1 |
| 同步 | 云同步（WebDAV/自建） | P2 |
| 输出 | 分享图片卡片、分享文本、导出 PDF/图片 | P1 |
| 主题 | 皮肤/信纸、深色模式 | P1 |
| 桌面 | 小组件 Widget | P2 |
| AI | OCR 文字识别、语音转文字 | P2 |

> P0 = MVP 必须；P1 = 接近完整版；P2 = 增强/生态依赖。

## 五、富文本编辑器设计（核心难点）

> 这是整个 App 工作量最大、最体现还原度的部分，单独详述。

### 5.1 存储模型：块结构（Block-based）
不存富格式 HTML，存**块数组 JSON**，每块带类型与内联样式 span，渲染/编辑/导出都基于它。

```json
{
  "blocks": [
    { "type": "heading", "level": 1, "spans": [{ "text": "标题", "styles": [] }] },
    { "type": "paragraph", "spans": [
        { "text": "普通", "styles": [] },
        { "text": "加粗高亮", "styles": ["bold", "highlight:yellow"] }
    ]},
    { "type": "checklist", "checked": false, "spans": [{ "text": "买牛奶", "styles": [] }] },
    { "type": "bullet", "spans": [{ "text": "无序项", "styles": [] }] },
    { "type": "image", "attachmentId": 1024 },
    { "type": "audio", "attachmentId": 1025 },
    { "type": "table", "rows": [[ ... ]] }
  ]
}
```

**块类型**：paragraph / heading(1-3) / bullet / numbered / checklist / quote / divider / image / audio / sketch / table / attachment。

**内联样式（span styles）**：bold / italic / underline / strikethrough / `color:#RRGGBB` / `highlight:color` / `size:small|normal|large`。

### 5.2 编辑器实现方案
- 每个文本块 = 一个可编辑单元，基于 Compose `BasicTextField` + `AnnotatedString`。
- 维护 `TextFieldValue.annotatedString` ↔ 块 span 的双向映射。
- 工具栏对选区应用样式：读取 `selection` 范围 → 修改对应 span → 刷新。
- 回车在列表/清单块自动续延同类型块；空块回车降级为普通段落（对齐华为交互）。
- 块级操作：拖拽排序、块类型转换、删除。

### 5.3 为什么自定义而不用 RichEditor 控件
- 安卓原生 `EditText`+Spannable 难以稳定承载清单勾选、内嵌图片/录音、表格混排。
- 块结构让"清单笔记""图文混排""导出 PDF/分享卡片"统一走一套渲染。
- 代价是工作量大（预计 2–3 周），属于必要投入。

### 5.4 渲染复用
同一份 blocks JSON 驱动三种渲染：
1. **编辑态**：可交互组件。
2. **预览/列表态**：只读 Compose。
3. **导出态**：渲染到 Bitmap → 拼接成长图（分享卡片）或写入 PdfDocument（导出 PDF）。

## 七、关键技术难点与方案

| 难点 | 方案 |
|------|------|
| 富文本编辑器 | 块结构 + Compose 自绘（第五章） |
| 全文搜索 | Room FTS4，写入时同步 plainText |
| 笔记加密 | 加密笔记的 contentJson/附件用 EncryptedFile 落盘；进入前 BiometricPrompt 验证 |
| 提醒可靠性 | AlarmManager(setExactAndAllowWhileIdle) + 开机广播重建闹钟；引导用户关闭省电限制 |
| 地点提醒 | GeofencingClient（需定位权限），P2 实现 |
| 录音内嵌 | MediaRecorder 录制 → 存附件 → 编辑器音频块内联播放 |
| 手写涂鸦 | Compose Canvas 采集笔迹路径 → 存矢量点或位图附件 |
| 分享卡片 | blocks 渲染到 Bitmap 长图，套信纸背景 |
| 导出 PDF | PdfDocument 分页绘制 |
| 备份 | 导出 zip（数据库 + 附件 + manifest），可导入还原 |
| 云同步(P2) | WebDAV 增量同步，按 updatedAt 做 last-write-wins，冲突存副本 |
| OCR(P2) | ML Kit 中文识别，离线 |

## 九、开发里程碑与排期（单人估算）

### Phase 0 — 工程地基（2–3 天）
- 工程搭建、Compose/Room/Hilt 接入、主题骨架、底部导航空壳。

### Phase 1 — MVP 可日常使用（约 3–4 周）
- 数据库与 Repository（笔记/文件夹）。
- 笔记列表：增删改、置顶、收藏、网格/列表。
- **富文本编辑器**：段落/标题/三种列表/内联样式/插入图片。（主投入）
- 全文搜索。
- 软删除 + 回收站。
- 本地自动保存。
> 里程碑：能替代华为笔记完成日常记录。

### Phase 2 — 接近完整版（约 4–6 周）
- 待办独立模块 + 时间提醒 + 通知。
- 标签系统。
- 笔记加密（指纹/密码）。
- 录音、手写涂鸦、表格。
- 分享卡片 + 导出 PDF/图片。
- 主题/信纸皮肤、深色模式。
- 本地备份导入导出。

### Phase 3 — 增强/生态替代（约 3–5 周）
- WebDAV 云同步。
- OCR 文字识别、语音转文字。
- 桌面 Widget。
- 地点提醒。

**总计：约 2.5–3.5 个月**（核心 MVP 约 1 个月可用）。
