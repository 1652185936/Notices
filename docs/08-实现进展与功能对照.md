# 08 实现进展与功能对照

> 本文记录项目实际实现进展，并逐项对照**华为笔记**功能。
> 随开发持续更新。代码以 CI 每次绿色构建为准（见 README「获取 APK」）。

---

## 0. 重要更正：对标对象

立项初期把目标误定为**华为备忘录**（手机自带的轻量速记 App）。
经核对（见 docs 内搜索结论与华为官网）：

- **华为笔记（Huawei Notes）** 才是要对标的 App，功能更专业。
- **无界笔记** 不是独立 App，而是**华为笔记内的核心功能/模式**——无限画布
  （写到边缘自动延伸、不封顶、最高 1000% 缩放、缩略图导航，依托鸿蒙渲染）。
- **华为备忘录** 是另一个更轻量的内置 App。

**因此本项目对标 = 华为笔记（含「无界笔记」无限画布模式）。**
"无界笔记"无限画布为本项目核心，已实现。

## 1. 形态划分

应用内有两种笔记形态，对应华为笔记的两种创作方式：

| 形态 | 对应华为笔记 | 入口 |
|------|-------------|------|
| **分页笔记** | 常规图文笔记 | 列表 FAB →「笔记」 |
| **无界笔记** | 无界笔记（无限画布） | 列表 FAB →「无界笔记」 |

## 3. 已落地的工程模块（实际代码）

```
data/
  local/        Room：实体/DAO/数据库（v3，含 isCanvas、folder.parentId 迁移）
  repository/   笔记/文件夹/待办/附件/录音/OCR/加密/偏好
  backup/       本地备份导入导出
  export/       长图/PDF 导出渲染
domain/
  richtext/     分页富文本引擎（块模型/样式算法/序列化）— 32 单测
  canvas/       无界笔记画布模型（世界坐标元素/序列化）
reminder/       待办提醒（闹钟 + 通知）
ui/
  notes/        列表 + 文件夹抽屉 + 新建入口
  editor/       分页编辑器 + 工具栏 + 手写画板
  canvas/       无界笔记无限画布
  todo/ search/ trash/ settings/ security/ theme/ navigation/
```

详见 docs/09（无界笔记画布设计）、docs/02（数据库）、docs/03（富文本引擎）。
