# 04 UI / 交互设计

> 视觉目标：高度贴近华为笔记的简洁风格（非逐像素复刻），交互习惯对齐，
> 让原华为笔记用户零学习成本上手。

---

## 1. 设计语言

### 1.1 设计 Token

```kotlin
// 颜色（浅色 / 深色）
Primary        #007DFF / #1F8BFF     // 仿华为蓝，可在设置中换主色
Background     #F1F3F5 / #000000     // 页面底
Surface        #FFFFFF / #1C1C1E     // 卡片
TextPrimary    #182431 / #E6E6E6
TextSecondary  #99182431(60%) / #99E6E6E6
Divider        #0D182431(5%) / #26FFFFFF
Danger         #FA2A2D
```

```
圆角:  卡片 16dp · 按钮 20dp(胶囊) · 输入框 12dp · 图片块 8dp
间距:  页面边距 16dp · 卡片间距 12dp · 块间距 8dp
字号:  H1 24sp/粗 · H2 20sp/粗 · H3 17sp/粗 · 正文 16sp · 辅助 14sp · 角标 12sp
触控:  最小可点击区域 48dp
```

### 1.2 主题
- 浅色 / 深色 / 跟随系统（DataStore 持久化）。
- 主色可选：华为蓝(默认)、绿、紫、橙。
- 深色模式下信纸自动映射暗色变体。

## 2. 页面规格

### 2.1 笔记列表页（首页）

```
┌─────────────────────────────┐
│ ☰  全部笔记            🔍  ⋮ │  顶栏：抽屉/标题(当前文件夹)/搜索/菜单
│ ┌─────────┐ ┌─────────┐    │
│ │📌 标题   │ │ 标题     │    │  双列瀑布流卡片（默认）
│ │ 摘要3行  │ │ [首图]   │    │  卡片 = 标题1行 + 摘要≤3行 +
│ │ 6月10日  │ │ 摘要2行  │    │        首图(若有,高120dp) + 日期
│ └─────────┘ │ 6月9日 ⭐│    │  📌置顶角标 ⭐收藏 🔒加密(摘要隐藏)
│             └─────────┘    │  清单笔记摘要 = 前3项+进度(2/5)
│                       (+)  │  FAB：新建（长按弹快捷菜单：
└─────────────────────────────┘        文本/清单/拍照/手写）
```

- **菜单 ⋮**：排序方式、网格/列表切换、批量编辑。
- **长按卡片** → 多选模式：顶栏变 `已选 n 项 | 全选`，底栏出现 `置顶 移动 删除`。
- **删除确认**：Snackbar "已移入回收站（撤销）"，5 秒可撤销，不弹对话框（降低摩擦）。
- 空状态：插画 + "点击 + 新建第一篇笔记"。

### 2.2 抽屉（文件夹导航）

```
全部笔记 (128)
收藏     (12)
─────────
📁 工作   (34)   ← 长按：重命名/改色/删除
📁 生活   (20)
未分类   (62)
─────────
+ 新建文件夹
回收站 · 设置
```

### 2.3 笔记编辑页

```
┌─────────────────────────────┐
│ ←        ↶ ↷   分享  ⋮      │  ⋮: 移动/标签/加密/置顶/信纸/删除/导出
│  标题（22sp 粗，placeholder）│
│  6月10日 19:30 · 326字       │  元信息行（只读，小字）
│ ┌─ 正文块列表 ──────────────┐│
│ │ ...                       ││
│ └───────────────────────────┘│
│ [B I U S A̲ 🖍 T̲ ¶]          │  格式工具栏：仅文本块聚焦时浮现于键盘上方
│ [🖼 ☑ 🎙 ✏ ⊞ —]            │  插入栏：常驻底部
└─────────────────────────────┘
```

- 工具栏分两层：第一层 B/I/U/S/颜色/高亮/字号/块类型，点颜色弹色板气泡。
- 块类型按钮弹出：正文/H1/H2/H3/无序/有序/清单/引用。
- **撤销/重做**按钮置灰逻辑跟随 UndoManager 栈。
- 键盘收起时格式工具栏隐藏，插入栏保留。
- 返回 = 保存并退出（无"保存"按钮，与华为一致）。

### 2.4 搜索页

- 顶部输入框自动聚焦；下方历史搜索 chips（最多 10 条，可清空）。
- 输入 ≥1 字符即时搜索（300ms 防抖）；结果卡片中关键词黄底高亮。
- 过滤行：`全部 ▾ 文件夹 ▾ 标签 ▾`。

### 2.5 待办页

```
快速添加输入框 [____________ +]
▾ 已逾期 (2)        ← 红色标题
  ○ 交电费    6月8日 ⏰
▾ 今天 (3)
  ○ 买牛奶
  ◐ 项目周报  18:00 ⏰ (1/3)   ← 有子任务显示进度
▾ 未来 / ▸ 无日期 / ▸ 已完成 (折叠)
```

- 勾选动画：圆圈→对勾 150ms + 项目淡出移入"已完成"。
- 左滑：删除；右滑：设提醒。点击展开详情（编辑、子任务、重复规则）。

### 2.6 其他页面（要点）

| 页面 | 要点 |
|------|------|
| 回收站 | 卡片右上角剩余天数角标；底部"清空回收站"红字；恢复=多选+恢复按钮 |
| 手写画板 | 全屏横竖可用；顶部工具条（笔/荧光/橡皮/颜色/粗细/撤销/清空/完成） |
| 图片查看器 | 黑底沉浸；双击缩放、双指缩放；底栏：另存/分享/删除/OCR(P2) |

| 信纸选择 | 底部抽屉横滑预览，点击即应用实时预览 |
| 分享卡片预览 | 生成长图预览 + 底部：保存图片/系统分享/水印开关 |
| 设置 | 分组列表：外观/提醒/加密/备份/同步(P2)/回收站/关于 |

## 3. 交互细节规范

### 3.1 手势汇总

| 手势 | 位置 | 行为 |
|------|------|------|
| 长按卡片 | 列表 | 进入多选 |
| 长按块手柄 | 编辑器 | 拖拽排序 |
| 左滑/右滑 | 待办项 | 删除/设提醒 |
| 下拉 | 列表页 | 不做刷新（本地数据无需刷新），仅露出搜索框（仿华为） |
| 双指缩放 | 图片查看 | 缩放 |

### 3.2 反馈规范
- 破坏性操作（彻底删除、清空回收站、覆盖恢复）→ 对话框二次确认，确认按钮红色。
- 可撤销操作（移入回收站、归档）→ Snackbar + 撤销，不打断。
- 轻反馈（勾选、置顶）→ 触觉 HapticFeedback.LIGHT。

### 3.3 动效
- 页面转场：Navigation Compose 默认 fade + slide（150–250ms）。
- 列表项增删：`animateItemPlacement`。
- FAB 长按菜单：径向展开 200ms。
- 原则：所有动效 ≤300ms，可在系统"减少动画"时关闭。

## 4. 无障碍与适配

- 全部图标按钮提供 contentDescription。
- 字体随系统缩放（sp），布局在 1.3x 字号下不溢出。
- 最小适配宽度 320dp；平板/横屏：列表页三列网格，编辑页限宽 720dp 居中。
- 深色模式全页面覆盖，无白闪。
