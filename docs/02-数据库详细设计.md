```kotlin
    val isPinned: Boolean = false,

    val updatedAt: Long = System.currentTimeMillis(),
```

### 1.3 NoteFtsEntity（全文索引）

```kotlin
@Fts4(contentEntity = NoteEntity::class)
@Entity(tableName = "notes_fts")
data class NoteFtsEntity(
    val title: String,
    val plainText: String,
)
```

说明：
- FTS4 外部内容表，由 Room 自动维护触发器与 notes 同步。
- 中文检索：FTS 默认 simple 分词对中文按单字切分，配合 `LIKE` 兜底已满足单机量级；
  若效果不佳，备选方案为引入 `icu` tokenizer 或应用层 n-gram 预处理（迁移点预留）。
- 加密笔记 `plainText=""`，天然不进索引。

### 1.5 AttachmentEntity

```kotlin
@Entity(
```

文件实际存储于 `context.filesDir/attachments/`，数据库只存相对路径。
**孤儿清理**：WorkManager 每周任务，删除无对应记录的文件（双向校验）。

## 2. DAO 接口（核心签名）

### 2.1 NoteDao

```kotlin
@Dao
interface NoteDao {
    // ---- 列表查询（响应式，UI 自动刷新）----
    @Query("""SELECT * FROM notes WHERE deletedAt IS NULL
              AND (:folderId IS NULL OR folderId = :folderId)
              ORDER BY isPinned DESC,
              CASE :sort WHEN 'updated' THEN updatedAt WHEN 'created' THEN createdAt END DESC""")
    fun observeNotes(folderId: Long?, sort: String): Flow<List<NoteEntity>>

    @Query("SELECT * FROM notes WHERE deletedAt IS NULL AND isFavorite = 1 ORDER BY updatedAt DESC")
    fun observeFavorites(): Flow<List<NoteEntity>>

    @Query("SELECT * FROM notes WHERE deletedAt IS NOT NULL ORDER BY deletedAt DESC")
    fun observeTrash(): Flow<List<NoteEntity>>

    // ---- 搜索 ----
    @Query("""SELECT n.* FROM notes n JOIN notes_fts f ON n.id = f.rowid
              WHERE notes_fts MATCH :query AND n.deletedAt IS NULL
              ORDER BY n.updatedAt DESC""")
    suspend fun searchFts(query: String): List<NoteEntity>

    @Query("""SELECT * FROM notes WHERE deletedAt IS NULL
              AND (title LIKE '%'||:kw||'%' OR plainText LIKE '%'||:kw||'%')
              ORDER BY updatedAt DESC LIMIT 200""")
    suspend fun searchLike(kw: String): List<NoteEntity>   // 中文兜底

    // ---- 写入 ----
    @Insert suspend fun insert(note: NoteEntity): Long
    @Update suspend fun update(note: NoteEntity)
    @Query("SELECT * FROM notes WHERE id = :id") suspend fun getById(id: Long): NoteEntity?
    @Query("UPDATE notes SET deletedAt = :now WHERE id IN (:ids)")
    suspend fun softDelete(ids: List<Long>, now: Long)
    @Query("UPDATE notes SET deletedAt = NULL WHERE id IN (:ids)")
    suspend fun restore(ids: List<Long>)
    @Query("DELETE FROM notes WHERE id IN (:ids)") suspend fun purge(ids: List<Long>)
    @Query("DELETE FROM notes WHERE deletedAt IS NOT NULL AND deletedAt < :before")
    suspend fun purgeExpired(before: Long): Int
    @Query("UPDATE notes SET isPinned = :pinned WHERE id IN (:ids)")
    suspend fun setPinned(ids: List<Long>, pinned: Boolean)
    @Query("UPDATE notes SET folderId = :folderId WHERE id IN (:ids)")
    suspend fun moveToFolder(ids: List<Long>, folderId: Long?)
}
```

搜索策略：先 FTS MATCH，结果为空且关键词含 CJK 字符时回退 `searchLike`，二者结果去重合并。

## 3. 类型转换与数据库类

```kotlin
class Converters {
    @TypeConverter fun toAttachmentType(v: String) = AttachmentType.valueOf(v)
    @TypeConverter fun fromAttachmentType(t: AttachmentType) = t.name

    version = 1,
```

## 4. 事务边界

| 操作 | 事务内容 |
|------|----------|
| 保存笔记 | update note + 重算 plainText/excerpt + 增删 attachments 记录（文件 IO 在事务外） |
| 删除笔记（彻底） | delete note（CASCADE 带走 tag 关联/附件记录）→ 事务提交后删文件 |
| 合并标签 | 重指 cross_ref + 删旧 tag |
| 备份恢复（覆盖） | 关库 → 替换 db 文件 → 重开（不走 Room 事务） |
| 备份恢复（合并） | 单事务批量 insert，id 重映射表在内存维护 |

## 5. 迁移策略

- `exportSchema = true`，`schemas/` 目录纳入 git。
- 每次版本号 +1 必须提供 `Migration(n, n+1)`；**禁止** `fallbackToDestructiveMigration`。
- 预留的演进点（设计时已留位，不需要破坏性变更）：
  - v2：FTS 分词方案升级（重建 notes_fts 即可，外部内容表数据无损）。
  - v3：同步字段扩展（notes 已预留 syncEtag/syncDirty）。
- 升级前自动触发一次本地备份（见文档 06 §5）。

## 6. 容量与性能预估

| 项 | 估算 |
|----|------|
| 1000 篇笔记（均 2KB JSON） | db ≈ 5–8MB，完全无压力 |
| 附件 | 大头在 filesDir，与 db 解耦 |
| 列表查询 | 命中 (isPinned, updatedAt) 复合索引 |
| 搜索 | FTS 索引查询，千级数据 <50ms |

列表页不加载 contentJson 全文 → 使用 `@Query SELECT id, title, plainText 摘要列` 的投影 POJO
（`NoteListItem`），避免大字段进内存。
