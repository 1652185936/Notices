# 07 测试与发布计划

---

## 1. 测试策略

| 层 | 工具 | 覆盖目标 |
|----|------|----------|
| 单元测试 | JUnit5 + kotlinx-coroutines-test | 富文本模型/算法、备份序列化、重复规则计算 |
| DAO 测试 | Room in-memory + Robolectric | 全部查询、级联、迁移 |
| UI 测试 | Compose UI Test | 编辑器关键交互、列表多选 |
| 手工测试 | HarmonyOS 4 真机 | 提醒可靠性、生物识别、分享、相机 |

**重点投入比例**：富文本编辑器算法单测 > DAO > 其他。编辑器是唯一"逻辑复杂到必须测试驱动"的模块。

## 2. 编辑器核心用例清单（必须全绿才进 Phase 2）

```
模型层:
 ✓ span normalize: 相邻同样式合并 / 空span剔除
 ✓ applyStyle: 全选加粗→再次全选取消 / 部分重叠选区 / 颜色互斥替换
 ✓ diff定位: 头部插入/中间删除/输入法整句替换/全选粘贴
 ✓ 劈块: 光标在span中间劈开样式不丢
 ✓ 合块: 退格合并后spans正确拼接normalize
 ✓ 序列化: 任意文档 serialize→deserialize round-trip 相等
 ✓ 未知块类型降级只读不丢数据
交互层:
 ✓ 清单回车续项 / 空项回车降级 / "- "自动转列表
 ✓ 撤销重做: 输入合并窗口 / 块操作独立op / 焦点选区还原
 ✓ 杀进程恢复: 自动保存兜底 ≤1s
```

## 3. 真机专项测试（HarmonyOS 4）

| 项 | 验证点 |
|----|--------|
| 提醒 | 锁屏2小时后到点必响；重启后提醒仍有效；省电模式行为 |
| 生物识别 | 指纹成功/失败3次回退PIN/无指纹设备 |
| 相机/录音 | 权限拒绝降级；来电打断录音不丢 |
| 分享 | 长图>10000px 微信/系统相册兼容 |
| 兼容 | 深色模式、字体1.3x、横屏平板 |

## 4. 构建与签名

```
buildTypes: debug(后缀.debug可并存) / release(R8+资源收缩)
签名: 自建 keystore（release.jks），密码记入个人密码管理器
  ⚠ keystore 丢失=无法覆盖升级，必须异地备份
版本: versionName 语义化 0.x.y(MVP期) → 1.0.0(Phase2完成)
分发: 侧载 APK（不上架）；构建产物 app-release.apk 自存网盘
```

## 5. 版本路线图

| 版本 | 内容 | 对应里程碑 |
|------|------|-----------|
| 0.1 | 列表+编辑器(文本/样式/清单/图片)+搜索+回收站+自动保存 | Phase 1 / MVP |
| 0.2 | 文件夹完善+多选批量+备份导入导出 | Phase 1 收尾 |
| 0.3 | 待办模块+提醒 | Phase 2 |
| 0.4 | 加密+录音+手写 | Phase 2 |
| 0.5 | 表格+分享卡片+导出PDF+信纸主题 | Phase 2 完成 → 1.0 |
| 1.1+ | WebDAV同步、OCR、语音转写、Widget、地点提醒 | Phase 3 |

**升级守则**：每个版本发布前 ① 跑全部单测 ② 真机过一遍第3节专项 ③ 先备份再覆盖安装验证数据完好。
