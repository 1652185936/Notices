## 1. 工程结构与依赖方向

```
ui ──→ viewmodel ──→ domain(usecase) ──→ data(repository) ──→ Room / FileStore
                         ↑ 仅领域模型(model)被各层共享，反向依赖禁止
```

Gradle 单 module（`app`）+ 包分层即可——单人项目不拆多 module，降低维护成本。

## 2. Repository 层接口

```kotlin
interface NoteRepository {
    fun observeNotes(folderId: Long?, sort: NoteSort): Flow<List<NoteListItem>>
    fun observeFavorites(): Flow<List<NoteListItem>>
    fun observeTrash(): Flow<List<NoteListItem>>
    suspend fun getNote(id: Long): Note?                  // 含解密（若加密）
    suspend fun createNote(folderId: Long?, template: NoteTemplate): Long
    suspend fun saveNote(note: Note)                      // 序列化+派生字段+落库
    suspend fun moveToTrash(ids: List<Long>)
    suspend fun restore(ids: List<Long>)
    suspend fun purge(ids: List<Long>)                    // 含附件文件清理
    suspend fun setPinned(ids: List<Long>, pinned: Boolean)
    suspend fun setEncrypted(id: Long, encrypted: Boolean) // 加解密转换，见文档06
    suspend fun search(query: String, filter: SearchFilter): List<NoteListItem>
}

interface AttachmentRepository {
    suspend fun importImage(noteId: Long, uri: Uri): Attachment    // 拷贝+压缩+入库
    suspend fun createAudio(noteId: Long): AudioRecordingSession
    suspend fun saveSketch(noteId: Long, strokes: SketchData, bitmap: Bitmap): Attachment
    suspend fun delete(attachmentId: Long)
    fun resolveFile(attachment: Attachment): File
}

interface TodoRepository { /* observeGrouped / add / setDone(含重复规则推进) / ... */ }
interface FolderRepository / TagRepository { /* 标准 CRUD + observe */ }

interface ReminderScheduler {                 // 系统闹钟封装
    suspend fun schedule(reminder: Reminder)
    suspend fun cancel(reminderId: Long)
    suspend fun rescheduleAll()               // 开机/时区变更后重建
}

interface BackupManager {
    suspend fun export(target: Uri): BackupResult
    suspend fun import(source: Uri, mode: ImportMode): BackupResult  // OVERWRITE/MERGE
}
```

## 3. ViewModel 与 UI 状态

每个页面一个 ViewModel，统一模式：

```kotlin
@HiltViewModel
class NoteListViewModel @Inject constructor(
    private val noteRepo: NoteRepository,
    private val folderRepo: FolderRepository,
    private val prefs: UserPrefs,
) : ViewModel() {

    data class UiState(
        val notes: List<NoteListItem> = emptyList(),
        val folders: List<FolderWithCount> = emptyList(),
        val currentFolderId: Long? = null,        // null = 全部
        val sort: NoteSort = NoteSort.UPDATED,
        val layout: ListLayout = ListLayout.GRID,
        val selection: Set<Long> = emptySet(),    // 多选模式（非空即处于多选）
        val isLoading: Boolean = true,
    )
    val uiState: StateFlow<UiState>   // combine(各 Flow) + stateIn

    fun onEvent(e: NoteListEvent)     // sealed interface：点击/长按/批量操作/切换...
}
```

页面清单与对应 VM：

| 页面 | ViewModel | 关键状态 |
|------|-----------|----------|
| 列表 | NoteListViewModel | 上述 |
| 编辑 | NoteEditorViewModel | EditorState(文档03) + 保存状态 + 附件操作 |
| 搜索 | SearchViewModel | query/results/history/filter |
| 待办 | TodoViewModel | 分组列表/展开项 |
| 回收站 | TrashViewModel | 列表+多选 |
| 设置 | SettingsViewModel | 主题/备份/加密开关 |

导航路由：

```
"notes" / "editor/{noteId}" / "search" / "todo" / "trash"
"settings" / "settings/backup" / "sketch/{attachmentId?}" / "viewer/{attachmentId}"
```

## 4. 关键时序

### 4.1 打开并编辑笔记

```
用户点击卡片
→ navigate("editor/42")
→ EditorVM.load(42): repo.getNote(42)
    ├─ isEncrypted? → BiometricPrompt → 解密 contentJson
    └─ deserialize → EditorState.blocks
→ 用户编辑 → blocks 变更 → dirty + debounce(1s)
→ serialize + 派生 plainText → repo.saveNote()（IO线程）
→ 返回键 → 若 dirty 同步保存 → popBackStack
```

### 4.2 插入图片

```
InsertBar 点🖼 → PhotoPicker 多选
→ 对每个 uri: attachmentRepo.importImage(noteId, uri)
    ├─ noteId==0(新笔记未保存) → 先 saveNote 拿 id
    ├─ 拷贝到 attachments/{noteId}/{uuid}.jpg（>2560px 压缩）
    └─ 插入 AttachmentEntity → 返回 Attachment
→ EditorState 在光标处劈块插入 ImageBlock(attachmentId)
→ 触发自动保存
```

### 4.3 待办提醒全链路

```
用户设提醒 → TodoRepo.setDue() → ReminderDao.insert
→ ReminderScheduler.schedule():
     AlarmManager.setExactAndAllowWhileIdle(RTC_WAKEUP, triggerAt, pendingIntent)
→ 到点 → ReminderBroadcastReceiver.onReceive
     ├─ 发通知（频道"待办提醒"，actions: [完成][稍后10分钟]）
     └─ repeatRule != NONE → 计算下次 triggerAt → 更新DB → 重新 schedule
→ 设备重启 → BootReceiver → ReminderScheduler.rescheduleAll()
通知 action "完成" → NotificationActionReceiver → TodoRepo.setDone(true)
```

### 4.4 分享长图卡片

```
编辑页"分享" → ShareCardScreen
→ Default线程: BlockExportRenderer.renderToBitmap(content, skin, 1080px)
    ├─ 逐块 Canvas 绘制（StaticLayout 文本 / 解码图片 / 表格画线）
    └─ 高度>16384px → 按比例缩放兜底
→ 预览 → 保存到相册 或 写入 cacheDir + FileProvider → 系统分享 Intent
```

## 5. 文件存储布局

```
filesDir/
 ├─ attachments/{noteId}/{uuid}.{jpg|m4a|png}
 ├─ attachments/{noteId}/{uuid}.sketch.json     // 手写矢量笔迹
 ├─ secure/                                     // 加密笔记密文附件（文档06）
 └─ draft_{noteId}.json                         // 保存失败兜底草稿
cacheDir/
 ├─ share/    // 分享临时长图（FileProvider 暴露，24h 清理）
 └─ export/   // PDF 导出临时文件
```

FileProvider authority：`com.yhx.notices.fileprovider`，仅暴露 `cacheDir/share` 与 `cacheDir/export`。

## 6. 后台任务（WorkManager）

| Worker | 触发 | 工作 |
|--------|------|------|
| TrashCleanWorker | 每日一次 | purgeExpired(30天) + 删除对应附件 |
| OrphanFileWorker | 每周一次 | 双向清理孤儿附件文件/记录 |
| AutoBackupWorker | 按设置(日/周) | BackupManager.export 到用户目录，轮换保留5份 |
| SyncWorker (P2) | 定时+手动 | WebDAV 增量同步 |

所有 Worker 设 `Constraints(requiresBatteryNotLow=true)`；备份/同步另加存储/网络约束。

## 7. 权限清单

| 权限 | 用途 | 申请时机 |
|------|------|----------|
| POST_NOTIFICATIONS | 待办提醒 | 首次设置提醒时 |
| SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM | 精确提醒 | 设提醒时引导 |
| RECEIVE_BOOT_COMPLETED | 重启重建闹钟 | manifest 静态 |
| CAMERA | 拍照插图/扫描 | 首次拍照时 |
| RECORD_AUDIO | 录音 | 首次录音时 |
| USE_BIOMETRIC | 加密验证 | 启用加密时 |
| ACCESS_FINE_LOCATION (P2) | 地点提醒 | 启用地点提醒时 |

读相册用 PhotoPicker（无需存储权限）；备份导出用 SAF（无需存储权限）。

## 8. 错误处理约定

- Repository 层不抛裸异常：返回值或 `Result<T>`；IO 失败记录到 `Timber` + 本地日志环形文件（512KB）。
- 数据库打开失败（极端损坏）→ 引导用户进入"恢复模式"页（从备份导入 / 导出原始 db 文件）。
- 编辑器反序列化失败 → 保留原 JSON 不动，以只读纯文本模式展示并提示（绝不覆盖写坏数据）。
