# 09 无界笔记（无限画布）设计

> 对标华为笔记的「无界笔记」模式：无边界画布、手写/文字/图片自由摆放、
> 平移缩放（10%–1000%）、纸张模板。本项目核心模块。

---

## 1. 坐标系统

- **世界坐标**：所有元素以世界坐标存储，画布无边界。
- **视口变换**：`offset`（平移，px）+ `scale`（缩放，0.1–10）。
- 屏幕 → 世界：`world = (screen - offset) / scale`
- 世界 → 屏幕：`screen = world * scale + offset`
- 绘制：`Canvas` 内 `withTransform { translate(offset); scale(scale, pivot=0) }`，
  元素直接按世界坐标绘制。

「自动延伸」由无边界世界坐标天然实现——平移即露出新区域，无需扩容。

---

## 2. 数据模型（domain/canvas/CanvasModel.kt）

```kotlin
@Serializable data class CanvasContent(
    val version: Int = 1,
    val background: String = "blank",   // blank/grid/lines/dots
    val elements: List<CanvasElement> = emptyList(),
)

@Serializable sealed interface CanvasElement { val id: String }

StrokeElement(id, tool, color, width, points: List<Float>)  // 扁平 x,y 序列
TextElement(id, x, y, text, fontSize, color)
ImageElement(id, x, y, width, height, attachmentId)
```

- 笔迹点扁平化为 `FloatArray` 省空间。
- 多态序列化（`type` 判别符），未知类型忽略（向前兼容）。
- 持久化：编码为 note.contentJson；note.isCanvas=true 区分形态；
  plainText 取文字元素拼接（供搜索/预览）。

## 3. 工具与手势（ui/canvas/CanvasScreen.kt）

单一 `pointerInput(tool)` 按当前工具切换手势检测器：

| 工具 | 手势 | 行为 |
|------|------|------|
| 移动 | `detectTransformGestures` | 平移 + 捏合缩放（绕触点中心） |
| 选择 | `detectDragGestures` | 命中元素→拖动；空白→平移；选中显示删除 |
| 钢笔/铅笔/荧光笔 | `detectDragGestures` | 采集世界坐标点 → 生成 StrokeElement |
| 橡皮 | `detectDragGestures` | 擦除路径命中相交笔迹（半径随缩放自适应） |
| 文字 | `detectTapGestures` | 点击放置文字框并进入编辑 |

笔型差异：荧光笔半透明加粗、铅笔偏细、橡皮按命中移除整笔。

缩放绕中心公式：
```
worldUnder = (centroid - offset) / scale
scale' = (scale * zoom).coerceIn(0.1, 10)
offset' = centroid - worldUnder * scale' + pan
```

## 4. 渲染

一个全屏 `Canvas` 内统一绘制（变换内）：
- **背景**：屏幕空间按 `offset/scale` 平铺网格/横线/点阵（无限延伸）。
- **笔迹**：`Path` + `Stroke(Round cap/join)`。
- **图片**：`ImageBitmap` 缓存（按 attachmentId），`drawImage(dstOffset,dstSize)`。
- **文字**（非编辑态）：`nativeCanvas.drawText`（变换内，世界字号）。
- **选中高亮**：包围盒描边。
- **实时笔迹**：拖动中预览路径。

**编辑态文字**单独用一个 `BasicTextField` 覆盖层，按世界→屏幕定位、字号乘 scale。

---

## 5. 元素操作（ui/canvas/CanvasViewModel.kt）

- `addStroke / addText / updateText / moveElement / deleteElement`
- `eraseStrokes(points, radius)`：点距判交，移除命中笔迹。
- `cycleBackground()`：切换纸张模板。
- 撤销：元素列表快照栈（结构性操作前入栈）。
- 自动保存：1s 防抖；退出空画布丢弃。

命中测试 `hitTest`：逆序（顶层优先）按元素包围盒判断；笔迹暂不可选。

---

## 6. 导出（data/export/ExportManager.kt）

`renderCanvas(content)`：
1. 遍历元素求内容包围盒。
2. 创建位图（限制最大边 3000px，超出按比例缩放）。
3. `translate(-min + margin)` 后逐元素原生绘制（笔迹/图片/文字）。
4. 输出：保存相册 / 转 PDF / 系统分享。
