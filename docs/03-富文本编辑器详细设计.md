# 03 富文本编辑器详细设计

> 整个 App 最核心、工作量最大的模块。本文定义数据模型 Schema、编辑状态管理、
> 选区与样式算法、块操作语义、撤销重做与序列化，达到可直接编码的粒度。

---

## 1. 数据模型

### 1.1 领域模型（Kotlin）

```kotlin
// 文档 = 块列表
data class NoteContent(
    val version: Int = 1,           // schema 版本，向后兼容用
    val blocks: List<Block>,
)

sealed interface Block { val id: String }   // id = UUID，块级 key，驱动 Compose 复用与撤销

// ---- 文本类块 ----
data class TextBlock(
    override val id: String,
    val kind: TextKind,             // PARAGRAPH / H1 / H2 / H3 / BULLET / NUMBERED / QUOTE
    val spans: List<Span>,
    val indent: Int = 0,            // 列表缩进层级 0..3
) : Block

data class ChecklistBlock(
    override val id: String,
    val checked: Boolean,
    val spans: List<Span>,
    val indent: Int = 0,
) : Block

// ---- 非文本块 ----
data class ImageBlock(override val id: String, val attachmentId: Long) : Block
data class AudioBlock(override val id: String, val attachmentId: Long) : Block
data class SketchBlock(override val id: String, val attachmentId: Long) : Block
data class DividerBlock(override val id: String) : Block
data class TableBlock(
    override val id: String,
    val rows: List<List<String>>,   // 单元格纯文本
) : Block

// ---- 内联样式 ----
data class Span(val text: String, val styles: Set<InlineStyle> = emptySet())

sealed interface InlineStyle {
    data object Bold : InlineStyle
    data object Italic : InlineStyle
    data object Underline : InlineStyle
    data object Strikethrough : InlineStyle
    data class Color(val argb: Int) : InlineStyle
    data class Highlight(val argb: Int) : InlineStyle
    data class FontSize(val scale: Float) : InlineStyle  // 0.85 / 1.0 / 1.25
}
```

**不变式（必须始终满足）**：
1. 相邻 Span 的 styles 不相同（保存前执行 normalize 合并）。
2. TextBlock.spans 至少含一个 Span（空块 = `Span("")`)。
3. 文档至少含一个块；删除最后一个块时替换为空 TextBlock(PARAGRAPH)。
4. 有序列表编号不存储，渲染时按连续 NUMBERED 块动态计算。

### 1.2 JSON 序列化（kotlinx.serialization，多态）

```json
{
  "version": 1,
  "blocks": [
    {"type": "text", "id": "a1", "kind": "H1",
     "spans": [{"text": "周末计划", "styles": []}]},
    {"type": "checklist", "id": "a2", "checked": true,
     "spans": [{"text": "买牛奶", "styles": []}]},
    {"type": "text", "id": "a3", "kind": "PARAGRAPH", "spans": [
       {"text": "记得", "styles": []},
       {"text": "重要", "styles": [{"s": "bold"}, {"s": "color", "v": -65536}]}
    ]},
    {"type": "image", "id": "a4", "attachmentId": 1024},
    {"type": "table", "id": "a5", "rows": [["品名","数量"],["牛奶","2"]]}
  ]
}
```

读取时遇到未知 `type` → 降级为只读占位块（向前兼容，旧版本 App 不损坏新数据）。

### 1.3 plainText 派生

保存时遍历 blocks 生成纯文本镜像：文本块取 spans 拼接；checklist 前缀 `[ ] / [x]`；
图片/音频输出 `[图片] [录音]`；表格按行 tab 分隔。用于 FTS 与列表预览。

## 2. 编辑器架构

### 2.1 组件结构

```
NoteEditorScreen
 ├─ EditorTopBar          (返回/撤销/重做/更多菜单)
 ├─ TitleField            (标题，独立于 blocks)
 ├─ LazyColumn            (块列表，key = block.id)
 │    └─ BlockRenderer    (按类型分发)
 │         ├─ TextBlockEditor      BasicTextField + AnnotatedString
 │         ├─ ChecklistBlockEditor 复选框 + BasicTextField
 │         ├─ ImageBlockView / AudioBlockView / SketchBlockView
 │         └─ TableBlockEditor
 ├─ FormatToolbar         (选中文本块时显示：B/I/U/S/颜色/高亮/字号/块类型)
 └─ InsertBar             (底部固定：图片/清单/录音/手写/表格/分割线)
```

### 2.2 状态管理（核心）

```kotlin
class EditorState {
    val blocks: SnapshotStateList<Block>
    var focusedBlockId: String?          // 当前焦点块
    var selection: TextRange             // 焦点块内选区
    var stickyStyles: Set<InlineStyle>   // 粘性样式（无选区时设置，影响后续输入）
    val undoManager: UndoManager
}
```

**焦点块单一原则**：任意时刻最多一个文本块处于编辑态，由它持有 `TextFieldValue`；
其余块渲染为静态 `Text(AnnotatedString)`，点击时切换焦点。这样：
- 性能：长文档只有 1 个活跃输入框，其余是轻量静态文本。
- 选区模型简单：选区永远在单块内（跨块选择 P2 再做，华为笔记跨块也仅支持复制）。

### 2.3 TextFieldValue ↔ Spans 双向映射

焦点块进入编辑态：
```
spans → AnnotatedString（每个 Span → addStyle(SpanStyle, start, end)）→ TextFieldValue
```
用户输入触发 `onValueChange(new)`：
```
diff(old.text, new.text) → 定位 (插入/删除区间)
插入：在对应偏移切开原 span，新文本继承「光标左侧 span 样式 ∪ stickyStyles」
删除：裁剪/移除覆盖区间内的 span
→ 更新 blocks[i].spans → 重建 AnnotatedString（带回 selection）
```
diff 用最长公共前后缀法（输入法单次变更必为连续区间，足够且 O(n)）。

### 2.4 样式应用算法

```kotlin
fun applyStyle(block: TextBlock, range: TextRange, style: InlineStyle): TextBlock
```
1. `range.collapsed`（无选区）→ 切换 `stickyStyles` 中该样式，返回原块。
2. 有选区：
   a. 在 range.start / range.end 处切分 span（split）。
   b. 判定语义：选区内**全部** span 已含该样式 → 移除；否则 → 添加（与华为/主流编辑器一致）。
   c. 互斥处理：Color/Highlight/FontSize 同类替换（先移除同类再加新值）。
   d. normalize：合并相邻同样式 span。
3. 工具栏高亮状态 = 选区内样式交集（全有才亮）。

### 2.5 键盘语义（块操作核心）

| 输入 | 上下文 | 行为 |
|------|--------|------|
| 回车 | 段落/标题中间 | 当前块按光标劈成两块，光标到新块头 |
| 回车 | 列表/清单项有内容 | 新建同类型块（checklist 继承 indent，checked=false） |
| 回车 | 列表/清单项为空 | 块降级为 PARAGRAPH（二段退出，对齐华为交互） |
| 退格 | 块首且非首块 | 与上一文本块合并（spans 拼接）；上块为图片等 → 仅移动焦点 |
| 退格 | 列表/清单块首 | 先降级为 PARAGRAPH，再退格才合并 |
| "- " 自动转换 | 段落开头输入 | 转 BULLET（"1. "→NUMBERED，"[] "→Checklist） |

### 2.6 块级操作

- **转换**：工具栏块类型按钮对焦点块原地转换（保留 spans，丢弃不适用属性）。
- **拖拽排序**：长按块左侧手柄进入拖拽（LazyColumn + 自实现 drag offset 交换）。
- **删除非文本块**：选中态（单击图片/表格出现边框）按删除键或菜单删除。
- **图片插入**：在焦点块光标处劈块 → 插入 ImageBlock → 后半段成新文本块。

## 3. 撤销 / 重做

### 3.1 模型：快照式 + 合并窗口

```kotlin
class UndoManager(private val limit: Int = 100) {
    private val undoStack: ArrayDeque<EditOp>
    private val redoStack: ArrayDeque<EditOp>
}

sealed interface EditOp {
    // 文本编辑：按块记录前后状态（块粒度快照，简单可靠）
    data class BlockChange(val blockId: String, val before: Block?, val after: Block?,
                           val indexBefore: Int, val indexAfter: Int) : EditOp
    data class Batch(val ops: List<EditOp>) : EditOp   // 劈块/合块等复合操作
}
```

- **合并窗口**：同一块内连续输入，500ms 内的变更合并为一个 op（避免一次撤销一个字）。
- 块结构操作（劈/合/增/删/排序/转换）立即截断合并窗口，独立成 op。
- 撤销同时还原焦点与选区（op 内记录 selection before/after）。
- 重做栈在任何新编辑后清空。

### 3.2 与自动保存的关系

自动保存只持久化当前状态，不影响 undo 栈；undo 栈仅存在于编辑会话内存中（退出页面即清，与华为一致）。

## 4. 自动保存管线

```
blocks 任何变更 → dirty=true
  └─ debounce 1000ms → serialize → 派生 plainText/excerpt → Room update (IO 线程)
onPause / onDispose → 若 dirty 立即同步保存
新建笔记首次保存时插入获得 noteId（此前附件先落临时目录，保存后移入 noteId 目录）
```

序列化在 Default 线程池执行；保存失败（极少）写入 `filesDir/draft_{noteId}.json` 兜底，
下次打开检测到草稿文件提示恢复。

## 5. 非文本块细节

### 5.1 ImageBlock
- 渲染：Coil 加载，宽度撑满内容区，按比例限高 320dp，圆角 8dp。
- 点击 → 全屏查看器（缩放/平移/另存）；选中态长按 → 删除/查看/OCR(P2)。

### 5.2 AudioBlock
- 卡片样式：播放按钮 + 波形进度 + 时长。全局同一时刻只播一条（EditorState 持有播放器单例）。

### 5.3 SketchBlock
- 显示渲染缓存位图；点击 → 全屏画板载入矢量笔迹继续编辑，保存时重渲位图。
- 笔迹格式：`{"strokes":[{"tool":"pen","color":-16777216,"width":4,"points":[[x,y,t],...]}]}`。

### 5.4 TableBlock
- 编辑态：单元格点击聚焦为小输入框；行列操作浮层（+行/+列/删行/删列）。
- 超宽横向滚动；单元格内不支持富格式（与华为一致，纯文本）。

## 6. 渲染复用（一份模型三种输出）

```kotlin
// 1. 编辑态   BlockRenderer(editable = true)
// 2. 只读态   BlockRenderer(editable = false)   // 列表预览、回收站查看
// 3. 导出态   BlockExportRenderer
fun renderToBitmap(content: NoteContent, skin: Skin, widthPx: Int): Bitmap  // 分享长图
fun renderToPdf(content: NoteContent, doc: PdfDocument)                     // 分页导出
```
导出渲染不走 Compose 组件树，直接 Canvas 绘制（StaticLayout 排版文本），
避免离屏 Compose 的复杂度，且可控分页。

## 7. 性能要求与对策

| 风险 | 对策 |
|------|------|
| 长文档（500+ 块）滚动 | LazyColumn 按需组合；非焦点块为静态 Text |
| 输入重组风暴 | 焦点块状态局部化（仅该块重组）；blocks 用 SnapshotStateList 细粒度更新 |
| 图片内存 | Coil 按容器尺寸采样；查看器单独加载原图 |
| 序列化卡顿 | 后台线程；2MB 以上 JSON 给出"笔记过大"提示（引导拆分） |

---

## 8. 开发顺序建议（编辑器内部）

1. 模型 + 序列化 + 单元测试（不变式、normalize、diff）。
2. 单文本块编辑 + 样式应用 + 工具栏。
3. 多块：劈/合/焦点切换/键盘语义。
4. 清单块 + 列表自动转换。
5. 撤销重做。
6. 图片块 + 插入栏。
7. 拖拽排序 → 表格 → 录音 → 手写（按 P1 顺序）。

> 第 1–2 步是验证整条技术路线的关键，预计 4–5 天；做完即可判断方案是否需要调整。
